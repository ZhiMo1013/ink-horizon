## 定位（写文案之前先想清楚这个）

**拆有意思的梗和现象，讲一些问题。**

不是"打假"，不是"辟谣"，不是"拆穿谁"。
是那种你在群里刷到、笑了一下、但回头又觉得有点不对劲的东西——
一个梗、一个现象、一句大家都在传的话。

**有意思**是前提。不好玩的不做。
**讲一些问题**是目的。只玩梗不落到问题上，那是鬼畜区。

语气：好奇，不是审判。想知道"这到底是怎么回事"，不是想说"你们都错了"。

## 四、长版（公众号 / 知乎 / 即刻，≤500 字）

```
用未曾见过的画面，讲未曾想清楚的问题。

这里是墨点视界，拆有意思的梗和现象。

**为什么挑"有意思"的？**
因为不好玩的，讲不出劲。
一个梗能传开，本身就说明它踩到了什么东西——
要么踩到了大家的共识，要么踩到了大家的隐痛。

**为什么讲"问题"？**
因为只把梗玩一遍，那叫鬼畜区。
一个梗里通常压着一个真问题，只是被笑点盖住了。
「10 万粉暴打 985211」——听着像段子，
底下压着的是"这件事到底值多少钱""谁在给它定价"；
「AI 一句话出片」——听着像炫技，
底下压着的是"那做这件事的人，还算什么"。

所以这个号做的事：
把梗摆出来，把里面的问题拆出来，
一项一项放到画面上，让观众自己看。

**不站队，不给结论。**
拆完是什么样，就是什么样。

更新不快，一期一两分钟，但要做到拆得干净。
```

## 八、写作硬规矩

1. **Slogan 一个字都不改。**「用未曾见过的画面，讲未曾想清楚的问题。」
   它是全账号唯一的固定句，所有版本开头或收尾都用它。
2. **不写制作方式。** 不提"代码画的""不配音""一个人做的"。这些是过程，不是价值。
3. **不做出承诺式背书。** "每个数字都带出处、都能查"听起来像免责声明，不像介绍。
   片子自己会证明；简介里说这个，反而像在提前辩解。
4. **主语是"梗和现象"，不是"我"。** 这个号的角色是把东西拆开给观众看的那个人，
   而不是"我是一个多么严谨的创作者"。
5. **slogan 说的是"怎么讲"，后面接的内容才说"讲什么"。** 两句不要重复同一个意思。
6. **语气是好奇，不是审判。** 不写"打假""辟谣""拆穿""别被骗了"。
   这个号不是来纠正别人的，是自己也想知道答案。
