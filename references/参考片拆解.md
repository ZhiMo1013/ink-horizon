## 二、差距分四层（从表到里）

### 1. 每格画面里东西太少（最致命）
我们占 12.2/60 格、亮区 3.7%；参考片占 21–27/60 格、亮区 8–11%。
**不是「我们东西小」，是「我们只有一样东西」。** 参考片每一帧都是：主视觉 + 一圈注释 + 角落元数据。

### 2. 完全没有「注释层」
- **剃刀**（网络图帧）：围绕主视觉有 13 个小标签——`在忙` `睡着了` `没看到` `生气了` `不想回` `故意` `忙到没空看手机` `可他明明在线，他看到了` `其实忍我很久了` `对我也没辙了` `有别人了` `一直在骗我，从一开始就是`，每个都用细线牵到对应节点。
- **光遗传**（细胞膜帧）：`衣藻` `① 感光` `② 开门，放电` `胞子膜` `细胞外` `细胞壁` `日泄` `进食` `运动皮层` `胡须，动了` `一滴水`。
- **银牌**（奖台帧）：`选手A` `选手B` `向上看：疼 / 因为你在被追` `向下看：暖 / 因为你已被拥有`，**还带虚线框 + 引导箭头指向画面具体位置**。
- **学鸟**（风线帧）：`托` `推` 两个大字 + 圆点 + 引线。

**我们有几行字幕，但没有一个「指着画面某一处」的标签。** 这是最大的空缺。

### 3. 用的是「信息图表」语言，不是纯图形
- **银牌 2.4 秒那张机场航班表**：表头 `出发 DEPARTURES`、列名 `航班 FLIGHT / 目的地 / 计划 / 实际 / 状态`、两行数据 `MU2381 上海 18:00 18:00 已起飞`（绿）、`CA1858 上海 18:00 17:NN 延误`（红）、右上角 `你到达机场 18:30`。**这就是一张真表格。**
- **银牌时间轴**：`A 的航班起飞` 圆点 + 一条从 17:55 到 18:35 的刻度尺 + `差 30 分钟` 标注 + `他们跟了` 竖线。
- **银牌标尺**：`1 分是痛苦，10 分是狂喜` + 一条 1–10 的刻度 + 游标 `4.8` `7.1`。
- **剃刀概率树**：`80%` 根节点 → 五个分支 `×0.8` `×0.8` `×0.8` `×0.8` `×0.8` → `33%` 巨字 + 算式 `0.8×0.8×0.8×0.8×0.8`。

我们只有柱子、圆圈、天平、尺子——都是「图形」，没有一张**表格**、**时间轴**、**带刻度的数轴**。

### 4. 数字没当成主角
- 参考片：`33%` ~200px 粉色巨字压右上；`× 27` 金色；`第 200 天` / `第 426 天` 右上大字；`2` `1` `3` 奖台编号约 120px；`66,730,287,907` 铺满大半画面。
- 我们：`8020` / `7500` 各 50px 灰白，缩在柱顶。

### 5. 角落元数据
剃刀左上恒有 `已发现 23:47 · 未被回复 2 小时 13 分`，左下有大号计时 `03:12`（随片推进）。光遗传左上 `LIVE PHOTORECEPTOR MEASUREMENT`、右上 `λ ≈ 470 nm` 之类的英文小注。银牌右上 `04:12:41:00` 时间码。
**这是「这是个正在发生的事件」的信号，比任何装饰都有效。我们完全没有。**

## 三、结构公式（三条片子共用的）

```
状态条/时间码（左上或右上，小字，恒定）
主视觉（占画幅 50–70%，主题明确，有持续微动）
环绕注释（5–13 个标签，细线牵到主视觉的某个具体点）
大数字或核心里程碑（角上，120–200px，强调色）
一句字幕（底部 46–47px，位置 0.905–0.947）
```

## 四、密度节奏

剃刀：**密（网络）→ 疏（奥卡姆单卡，只有两行字）→ 中（3D 轨道）→ 疏（单行星）→ 密（概率树）→ 疏（折线）→ 最密（回头网络）→ 最疏（只剩一个微信气泡）**。

不是一直满，是**满—空—满—空**的呼吸，而且最后一帧真的只剩一个气泡和一粒已读小字。

我们相反：全程中等偏空（12 格），既不密也不空，所以既不震撼也没有留白。

## 五、叙事骨架（四条一致）

具体场景开场 → 抛反直觉概念 → 可视化把概念「演」出来 → 回到开场场景但含义变了 → 片名卡 + 参考文献小字。

结尾片名卡：
- 银牌：`银牌的眼泪` + 参考文献行
- 学鸟：`学鸟` + `道·法·术·器` + `别学鸟的样子，学鸟学的那个。`
- 光遗传：`趋光` + 奖项名 + 两位得主

**我们的片名卡已有，不用改。**

## 六、动手清单（按性价比）

1. **加注释层**（收益最大）：每个场景给主视觉配 5–12 个带牵引线的标签。
2. **数字放大到主角级**：50px → 110–140px；`310 万` → 130px。
3. **加角落状态条**：左上「数据核对 2026-11-03 · 3 个来源」，右上时间码，左下进度。
4. **补一张真表格 / 一条真时间轴**：02 段 C 小节的两根柱子改成一张对照表 + 一条数轴。
5. **填掉 4 段长静段**（4.9–8.0 / 54.1–56.1 / 89.9–93.9 / 131.9–134.5）：加缓漂、呼吸、粒子流 —— 参考片 0–1 段。

字幕已按参考片规格调好：52px / 基线 0.934。
